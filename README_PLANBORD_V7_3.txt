JP Planner v7.3 - visueel dagplanbord

Deze patch wijzigt alleen templates/planning.html.

Nieuw:
- bestaande dienstenplanning blijft bovenaan intact;
- daaronder verschijnt per dag een tijdlijn van 08:00 tot 02:00;
- activiteiten staan links per rij;
- elke klus staat op het juiste tijdstip als blok;
- blok toont tijd, medewerker(s), voertuig en locatie;
- groen = volledig gepland, oranje = waarschuwing/controle, rood = niet compleet gepland;
- meerdere klussen van hetzelfde spel staan op dezelfde rij.

Upload naar GitHub en overschrijf alleen templates/planning.html.
